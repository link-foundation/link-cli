validation setup. It runs compilers sequentially within the 2.92 GiB budget.
The first complete attempt exposed a repository Dependabot watch-list omission;
all 217 repository checks pass after fixing that configuration. C# was rerun in
both configurations after the final provider/dependency and response-control
changes. Final counts below use those reruns, not the earlier C# reports.

- Actual WASM: 496 passes, zero failed/ignored; LLVM branch coverage collected.
- JS: 168 passes; all eighteen production modules enforce 100% line, branch and

Component and failure evidence:
- Independently authored UTF-8 BLOB/schema/sequence vectors are consumed by native
  Rust, C# and JS tests; leading U+FEFF, NUL and Unicode bytes survive reopening.
- Busy/stale owners, wrong identities/schemas, malformed bytes, setting drift,
  failed construction/close retry, finite SQLITE_FULL and before/after actual
  COMMIT faults retain exact committed prefixes and fence later component use.
- Forty actual child exits per native language cover five commit points across
  both maps, logical encodings and physical delta choices. Reopening under the
  opposite logical encoding and following writes preserve the exact SQL group.
- Intact copied WALs retain a new commit; a torn final frame or checksum damage
  recovers the prior checkpoint. quick_check and following writes pass.
- Four C# missing-scalar regressions first fail, then reject absent provider rows
  rather than interpreting null as zero. Thirty-five adapter cases and eight
  bounded exit theories now pass (43 focused cases total).
- Nine independent existing-code regressions first fail because JS TextDecoder
  strips a leading U+FEFF from opaque payloads. Literal/framing/file decoding now
  preserves the bytes while retaining strict malformed-UTF-8 rejection.
