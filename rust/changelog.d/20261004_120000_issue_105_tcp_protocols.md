Added LiNo substitution operations over TCP (issue #105): a dot-stuffed UTF-8 `TextLinoProtocol` and an interchangeable `BinaryLinoProtocol` whose packets carry the number of links and grow reference widths from 8 to 16, 32 and 64 bits, with optional external (Hybrid) references, a variable-length sequence section and progressive widths. `LinksServer`/`LinksClient` and the new `clink --serve`/`--connect` options (`--protocol`, `--external-references`, `--sequences`, `--progressive-widths`) run create, read, update and delete queries over either protocol.

Upgraded `links-notation` to 0.22.0. In earlier versions, parse time grew exponentially with nesting depth, so one short message could stall a server.
