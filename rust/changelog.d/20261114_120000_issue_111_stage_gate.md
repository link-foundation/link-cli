Rust CI jobs now start only after the JavaScript stage (lint, `npm run test:js`, parity check) passes for the same commit. The Rust suite loads the shared golden fixtures in `parity/golden-fixtures.json` and CI checks its receipt (issue #111).

The release job now pushes its version commit with the release deploy key, because `main` requires the three stage checks. When that push is declined, the error says how to restore the key.

`links-notation` is updated to 0.31.5, which was released while this change was in review and failed the Dependencies check.
