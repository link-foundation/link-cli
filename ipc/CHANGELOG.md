# Changelog

## 0.1.0

Initial optional byte-stream IPC decorator package for issue #140: shared
memory, memory-mapped files, disk files, signals, POSIX queues/FIFOs, Unix
sockets, TCP/UDP, anonymous/Windows named pipes, ALPC, WM_COPYDATA and local
mailslots. Configurable client/server relays preserve both existing LiNo wire
formats and support mixed stacks. Native and real-server checks run in CI.
